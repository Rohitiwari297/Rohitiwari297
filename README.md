## 👨‍💻 About Me

I'm a **Full Stack Developer** with ~2 years of hands-on experience shipping production applications on the **MERN stack** with **TypeScript**. I'm strongest on the backend: designing clean REST APIs, secure authentication, caching and deployment, and I build the React / Next.js frontends that sit on top of them.

> I care about code that is **secure, fast and maintainable**, and about shipping features that real users rely on.

**What I bring to a team**

- 🔐 **Secure by design**: role-based access control (RBAC), OTP login, HTTP-only JWT cookies, rate limiting
- ⚡ **Performance-minded**: Redis caching and Nginx reverse proxy / load balancing to cut latency
- ☁️ **Deployment ownership**: AWS EC2, Linux VPS and cPanel with PM2 and Nginx
- 🧩 **End-to-end delivery**: database schema → REST API → React UI → live deployment
- 🤝 **Collaborative**: worked with designers, backend engineers and product teams in Agile teams
- 🤖 **AI-assisted workflow**: ChatGPT and Claude for refactoring, debugging and faster delivery

🌱 **Currently learning:** TanStack Query · System Design · advanced backend patterns
